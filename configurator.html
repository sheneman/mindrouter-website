Sizing assumptions
Models are served quantized (NVFP4 primary; FP8 where VRAM allows) on vLLM-class serving stacks. A model must fit within one server's pooled GPU memory (DGX Spark may pair two linked units). Concurrency assumes ~35% of connected chat users generate at once and API traffic peaks at ~6× its weekly average. Power assumes each GPU averages ~50% of its maximum draw during inference serving (band shown: 40–65%), plus platform overhead. Prices are USD street-price ranges compiled from vendor and reseller listings (see the data date above), plus a 3–10% integration allowance. Supermicro is used as the reference server vendor. Estimates only — not a quote.
